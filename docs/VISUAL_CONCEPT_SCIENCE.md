# Four-step science and decision scenes

Implemented on 11 October 2026 in the new `ProjectConceptScience.tsx`, its CSS module, `projectConceptScience.ts` metadata and `projectConceptScienceCopy.ts`. These fifteen scenes are controlled by the shared project's Core idea player. The child owns no timer, network request, mutation, uploaded file or model invocation. A passed `step` selects one of four deterministic snapshots; width, opacity, case routing and point-position transitions honour reduced motion.

The scene is a compact introduction before the full experiment. Its caption says what changed and its note identifies saved results versus teaching calculations. It does not replace the detailed controls, original report or interpretation in the full demo. All authored scene and metadata prose has explicit Simplified and Traditional Mandarin; UK/US English follows the maintained project translation path.
