# Artwork and source media

Interface icons use one System 7 family with COVERD's original owned logo. Scientific figures, project screenshots and personal photographs remain content, with their original meaning and source records intact.

## Shared desktop and app icons

The current family contains **42 canonical subjects**, totalling **14,964,330 bytes**: 41 authentic transparent **1,254×1,254px** generated originals in [`public/system7-icons`](../public/system7-icons/) and [COVERD's original transparent 512px logo](../public/coverd-logo-black-on-transparent.png). [View every subject at 16, 32 and 48 pixels, plus a 96px fidelity preview](assets/system7-icon-family.png). All 41 generated PNGs are recovered native outputs, copied unchanged rather than enlarged from smaller files. Thirty match the recorded generation hashes; the earlier 11 were identified by exact RGBA correspondence between their native originals and the retired nearest-neighbour 128px deliveries. No new generation was needed. Book and Desk Accessories retain their reviewed second-generation originals. Dark stepped outlines, grey/white faces and muted periwinkle/ochre details establish the family.

[`SYSTEM7_ICONS`](../src/lib/system7Icons.ts) owns each image path. [`iconIdentity`](../src/lib/iconIdentity.ts) explicitly maps 26 applications, 41 projects, seven games, 23 Home Lab services and three contact services. Desktop shortcuts, menus, the window switcher, Finder, accessory launchers, project artwork and interior navigation use the same image at every size. Orbital Lab has one orbital icon throughout. Shared slots are 16px for inline/menu/navigation icons, 32px for cards, Finder results, Contact destinations and the phone window switcher, and 48px for desktop launchers and primary project headings. Large boot and empty-state illustrations retain their deliberate sizes. Window titles are centered text; the active application icon appears at the right of the main menu bar. A new app/project needs an explicit entry; missing identities fail validation rather than silently acquiring a generic folder.

[`System7Icon`](../src/components/System7Icon.tsx) centers each subject using its measured optical bounds in [`system7IconBounds`](../src/lib/system7IconBounds.ts). Its longest visible dimension occupies 90% of a square frame, with equal horizontal and vertical scale. Bounds measure alpha at least 16/255 so almost-transparent generation dust outside the subject does not shrink or miscenter the drawing. This threshold is presentation metadata only: no source alpha, colour, pixel or PNG byte is changed. Intrinsic dimensions reflect the native files, and content-derived URL revisions refresh cached artwork. Generated subjects retain pixelated sampling with no added smoothing. Their existing source alpha and colour variation remain intact. COVERD retains smooth sampling and a white backing with a crisp black edge, keeping its original black circular logo visible against paper, selected navy and the patterned desktop.

The old SVG miniatures, bespoke accessory drawings, project cover thumbnails and VideoMate mark have been removed from identity surfaces and delivery assets. The generated COVERD résumé/coin substitute is also retired; COVERD's original logo now identifies the app and project everywhere, with its actual wordmark retained in product content. Browser, Apple and PWA icons are separate required-size delivery formats derived directly from the native profile image with the same 90% proportional optical frame. Every sampled RGBA pixel comes from that source without interpolation or a smaller intermediate sprite; the original profile PNG remains unchanged. The maskable format adds an opaque backing inside its guaranteed safe region. Safari's required monochrome mask is a pixel projection of the same artwork. Browser/PWA metadata uses cache revision v6.

[Exact prompts, source hashes, native dimensions and delivery hashes](SYSTEM7_ICON_PROMPTS.json) record all 42 subjects in one manifest. The retired preparation reduced 30 native originals to a 24px artwork field on a 32px canvas before enlarging them to 128px. The other 11 originals were reduced directly to 128px. Both discarded native detail. Those derivatives are now replaced by the unchanged source PNGs; their former hashes and preparation records remain in the manifest. No crop, resampling, alpha rewrite, palette reduction or artificial enlargement is applied to canonical artwork. COVERD retains its original 512px delivery, and the retired substitute's generation record remains nested in the manifest. Temporary drafts, screenshots and recovery receipts stay outside tracked documentation.

Run `npm run check:icons` to verify real PNG decoding, alpha bounds, dimensions, equal scaling, complete identity coverage, shared normal/miniature paths, project artwork, favicon frames and maskable safety. The compiled browser audit is `scripts/check-system7-browser.mjs`; it checks actual images and app/project identities across the supported locales and desktop/phone layouts. These checks complement visual review of the rendered subjects and chrome; they do not score legibility by themselves.

With an isolated production build and preview running, set `PLAYWRIGHT_CORE_PATH` to an external Playwright installation and `REVIEW_ORIGIN` to that preview. Run `BROWSER_ENGINE=chromium node scripts/check-system7-browser.mjs`, then repeat for Firefox and WebKit. `BROWSER_ENGINE=chromium node scripts/check-finder-labels.mjs` checks the actual application titles, descriptions, localized and English search aliases, visible icon decoding and dismissal focus; repeat it for Firefox and WebKit. `node scripts/check-finder-loading.mjs` exercises delayed and failed optional chunks, visible dismissal, Escape, focus restoration and late delivery; it also audits the dialogs when `axe-core` is installed alongside Playwright. All runners save raw results under ignored `.codex/reports/`. The full icon inventory uses a recorded 250ms navigation delay; unpaced history-write stress is a separate check with the limitation documented in the current audit.

## Institution branding

Education records use official institution marks separately from the generic university application icon. ## Saved scientific images

App icons are illustration. Scientific image viewers use separately reviewed saved source outputs. The current inventory includes 150 GNN flow frames, FNO/U-Net stills, microscopy inputs and Grad-CAM views, plus the MRI reconstruction comparison: **172 scientific images** in total. `scripts/fixtures/scientific-media.mjs` pins their bytes and dimensions.

The [MRI figure record](MRI_RECORDED_FIGURE.json) identifies the exact IX repository revision, source file, hashes and delivery conversion. The saved figure's example metrics remain distinct from the reconstruction study's aggregate results. English labels embedded in source images remain intact; surrounding captions and controls are translated. Do not generate, retouch or relabel illustrative images as experimental evidence. The original scientific figure is resized/re-encoded only, with its panels and labels intact.


## Retired artwork

The conceptual Microrobot, CFD and Finance covers and their original prompts remain in Git history. Their former delivery files were `public/project-art/{microrobot,neural-cfd,finance}.webp`; VideoMate's former mark was `public/project-art/videomate-mark.svg`.
