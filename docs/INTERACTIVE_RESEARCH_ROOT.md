## Coordinator additions

COVERD replaces the static pipeline/principles wall with an editable worked example. Six dimensions look for literal statements in the example application; a missing statement produces a follow-up question. The result updates when the visitor adds a reply, and JSON export contains the actual changed record. The real product uses specialist agents; this small browser matcher does not call them or make hiring decisions.

Insurance matching fills only missing fields using explicitly fictional follow-up results. Loading history and wording alone leaves authority unconfirmed. Confirming all required checks permits a broker-review pin; undo removes the new records and the pin. Existing values and broker ordering stay intact, and no aggregate is introduced.

The venture replay protects the reserve, pays the fixed milestone cost in month one and monthly operating costs thereafter. Saving a plan captures its current spending assumption. At the default seven-month milestone, a 60% increase changes remaining operating cash from £326,000 to −£18,400. The replay, chart and saved comparison agree; these are invented planning inputs.

Three science overviews now show authentic public images. Their short feature lists explain the task before model names and metrics. Fourteen demo invitations describe the new interaction and the result to inspect. The personal study description uses first-person authorship.

## Viewability repair and verification boundary

The compiled product audit exposed a phone-guide input lock after resizing to desktop: CSS hid the guide while its modal state kept the desktop inert. A resize listener now dismisses a guide that no longer belongs to the compact viewport. This is verified by resizing an undismissed guide in the final compiled build. The Traditional Chinese Ultra rule itself worked after guide dismissal: moving Rename before Convert produced `Photo-png.webp` and kept the original.

Development hot reload occasionally removed lazily loaded CSS or reset an active experiment while other files changed. Failed captures and fresh-reload observations are retained. Final grading includes a compiled replay so a development-cache artifact cannot substitute for the delivered behavior.

The mathematical additions operate on teaching inputs. Saved research images/results retain their source metrics and evaluation conditions. Browser interactions are labelled where they use fictional data, simplified recurrences or fixed saved pixels. Original raw datasets, account state and native operator media are not exported.

Independent review results are in INTERACTIVE_RESEARCH_DECISIONS.md, INTERACTIVE_RESEARCH_LEARNING.md and INTERACTIVE_SCIENCE_CROSS_REVIEW.md. Reviewers score purpose, understandable changed outcomes, interaction/navigation, phone readability and visual consistency. A score covers the described journeys, not every possible state or a recruited user study.
