## Reproduce

Use locked dependencies and Node 22. Ordinary release checks do not need external browser packages or change a production server:

```sh
npm ci
npm run check:release
npm run --silent audit:repository
```

If a dev server uses `.next`, `check:release` builds separately under `.next-build`. Keep browser tools outside application dependencies:

```sh
qa_tools=$(mktemp -d)
npm install --prefix "$qa_tools" --no-save playwright@1.63.0 esbuild@0.28.2 axe-core@4.13.0
"$qa_tools/node_modules/.bin/playwright" install chromium firefox webkit
export PLAYWRIGHT_CORE_PATH="$qa_tools/node_modules/playwright"
audit_preview=$(mktemp -d)
cp -a .next-build/standalone/. "$audit_preview/"
mkdir -p "$audit_preview/.next-build"
cp -a .next-build/static "$audit_preview/.next-build/static"
cp -a .next-build/react-loadable-manifest.json "$audit_preview/.next-build/"
cp -a public "$audit_preview/public"
(cd "$audit_preview" && PORT=5189 HOSTNAME=127.0.0.1 NODE_ENV=production node server.js)
```

In another shell, export the same Playwright path and `REVIEW_ORIGIN=http://127.0.0.1:5189`. Install Linux browser libraries when required. Clear coverage filters (`DEEP_GROUP`, `DEEP_LOCALES`, `DEEP_WIDTHS`, `DEEP_SLUGS`, `REVIEW_GROUP`, `LOCALE_PATTERN`, `AXE_GROUP`, `AXE_PROJECTS`, `ICON_LOCALES`, `ICON_WIDTHS`) before claiming complete matrices.
